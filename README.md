# Basic Grammar 111

A static Japanese-English flashcard page built with HTML, CSS, and vanilla JavaScript. Each card starts in Japanese and flips to English when activated. When another card is activated, the previously open card returns to Japanese.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file server.

## Publish with GitHub Pages

In the repository settings, enable GitHub Pages and choose the branch and repository root as the publishing source. The site uses relative asset paths and needs no build step or backend.

## Edit the cards

Edit the `flashcards` array in `script.js`. Keep IDs unique and maintain exactly 111 entries if you want to preserve the 111-card collection.
